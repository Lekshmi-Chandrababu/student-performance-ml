# 🎓 Student Performance Prediction using Machine Learning

## 📌 Project Overview
This project predicts student math scores based on demographic and academic features using Machine Learning techniques.

## 📊 Dataset
The dataset contains student details such as:
- Gender
- Parental education
- Lunch type
- Test preparation course
- Reading & writing scores

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 🔍 Machine Learning Model
- Linear Regression

## ⚙️ Workflow
1. Data loading and preprocessing
2. Encoding categorical variables
3. Train-test split
4. Model training
5. Model evaluation
6. Visualization of results

## 📈 Results
The model predicts student math scores with reasonable accuracy and demonstrates the application of regression techniques.

## 🚀 How to Run
1. Clone the repository
2. Install required libraries
3. Open `student_performance.ipynb`
4. Run all cells
